Tekan Putar atau Maju untuk menjalankan algoritma Prim dari simpul awal.

Pseudocode Prim

  1. T = {s}, mst = []
  2. masukkan sisi (w, s, v) ke PQ
  3. selama PQ ada isi dan |T| < |V|:
  4. (w, u, v) = PQ.ambil_min()
  5. jika v sudah di T: lewati sisi
  6. tambah v ke T, (u, v, w) ke mst
  7. tiap tetangga x dari v luar T:
  8. PQ.tambah(w(v, x), v, x)
  9. kembalikan mst

Kaitan algoritma Prim dengan paper optimasi energi WSN

Halaman ini merujuk pada artikel Saad dkk. (2024), "Enhancing energy balance in wireless sensor networks through optimized minimum spanning tree" (PeerJ Computer Science 10:e2269).

Isi berkas referensi dan simulasi kelompok

File asli dari penulis paper di folder referensi/ berisi contoh Kruskal 4 node (codeeee.py), skrip MATLAB 50 node statis (peerj-cs-10-2269-s003.m), dan lima berkas CSV nilai ECP. Kode bawaan tersebut belum mencakup simulasi banyak ronde.

Untuk mempelajari alur kerjanya secara utuh, kelompok membuat kelompok/simulation.py dengan 30 node pada area 200x200 m selama 1.500 ronde (baterai awal 0.5 J, ukuran paket 4.000 bit, jarak ambang 87.71 m).

Mengapa bobot sisi memakai sisa energi

Pohon MST dengan jarak biasa selalu memilih garis terpendek, sehingga node di bagian tengah terus dilewati paket dan cepat kehabisan baterai. Pada mode Sadar energi, bobot sisi mengikuti rumus di build_energy_aware_prim_mst: 

w(v, nxt) = 0.50 * (jarak / d_maks)
          + 0.35 * (1 - min(E_v, E_nxt) / (1.1 * E_awal))
          + 0.15 * (derajat(v) / N_hidup)

Coba geser turun baterai node N2 di panel kiri. Algoritma Prim akan memutar jalur lewat node lain agar baterai yang hampir habis tidak terus dibebani.
